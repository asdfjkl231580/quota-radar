## 必须保留的结构（GPT 不能改）
1. 顶部：站名「额度雷达」+ 一句话「Codex、Claude 什么时候送额度，中文一眼看清」+ 四个导航（首页 / Codex / Claude / 常见问题）。
2. 两张状态卡并排（手机上上下叠）：左 Codex（蓝色系）右 Claude（橙色系）。卡内从上到下：厂商名 → 超大字「昨天」→ 小字日期 → 标签「重置卡」+ 一句中文 → 适用套餐 + 「原帖」链接 → 底部虚线下一行「官方下次：尚未公布 · 近 30 天 N 次」。
3. 时间线：左侧一根竖线加圆点，每条：厂商 + 日期 + 彩色标签（绿=全员重置、橙=重置卡、蓝=提额省额）→ 一句中文加粗 → 灰色小字「适用 / 账号 / 原帖」→ 可折叠「英文原文」。
4. 常见问题：折叠列表。
5. 底部：一行灰字数据说明。

## 视觉方向（可发挥的地方）
- 气质：像一块安静的「机场信息板」或「值班室看板」，让人一眼相信这是记录不是营销。
- 色：浅米白底（不要纯白），墨黑字，两个厂商各一个强调色（Codex 蓝、Claude 橙），三个标签色（绿/橙/蓝），别再加别的色。
- 字：中文用系统黑体即可，大数字可以用一个有辨识度的等宽或窄体。
- 网格：8px 网格，圆角只用 6 / 10 / 16 三档，字号只用 12 / 14 / 16 / 20 / 30 五档。
- 不要：渐变、玻璃拟态、3D 图标、机械翻牌动画（同类站已用过）。
