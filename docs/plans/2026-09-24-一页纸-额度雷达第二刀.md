# 一页纸 · 额度雷达第二刀：精准抓取（2026-09-24 晚）

## 做什么
官方一发送额度的帖子，网站在 10 分钟内自动更新，卡片时间精确到原帖发布秒。官方提前放话（预告）也能在卡片上看到。每条记录点开能看到原帖卡片（头像、账号、原文、时间）。

## 不做什么
- 不预测、不算概率。
- 不自动翻译中文（智能体太慢且带命理引用），中文一句话仍人工写，自动上线的条目先标「待整理」。
- 邮箱订阅不在这一刀：需要你先开一个邮件服务账号（我推荐后再定），第三刀做。
- 不截图 X 页面，原帖卡片用接口数据画。

## 怎么算做完
1. 我跑一次哨兵脚本，终端显示三处线索源都查到、无新条目。
2. 我把一条旧事件临时删掉再跑哨兵，它自动把这条补回来、重建站点、发布、飞书通知你「自动收录 1 条，待整理」。
3. 打开时间线任一条，看到原帖卡片：头像 + 名字 + @账号 + 原文 + 时间 + 「在 X 上看」。
4. 若最近有预告帖，卡片下方出现一行「预告：…」。
5. 装上定时任务后，10 分钟一次自动跑，日志在 data/sentinel.log。

## 我替你定的决定
- 定了时间只认原帖发布时间（fxtwitter 返回，精确到秒），因为两个参考站也是这个口径，这是最硬的事实。
- 定了三层线索：两参考站接口每 10 分钟（免费）→ TikHub 主账号每小时（约 $0.5/天）→ 每天两次全账号兜底。三层任何一层发现新帖，都要过 fxtwitter 原帖核验才算。
- 定了「能自动分类就自动上线」：原文含 banked → 重置卡；含 reset 且是完成时态 → 全员重置；含 increase/credit/more usage → 提额；这三类自动上线标「待整理」，我随后补中文。
- 定了「预告」只进待办不自动上线，因为预告措辞太多样，机器判错会误导。我确认后才显示。
- 定了自动上线后自动 build + vercel --prod，不等人。
- 定了定时任务文件给你但不自动装（你的规矩），装法一行命令在交付里。
- 定了原帖卡片头像存本站（X 图片域名国内打不开）。
