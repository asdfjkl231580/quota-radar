- 感觉：简单、明亮、醒目、活泼、年轻、可信。大数字 + 少文字 + 强颜色。
- 信息优先级：大数字 > 事件类型 > 最近记录（4 条）> 常见问题（4 条，折叠）。
- 尺寸：桌面基准 1440×900，容器 min(1200px, 100% - 64px)；手机基准 390×844，另测 375/430，左右 16px；断点 1280/1024/768/430/390。
- Header 72px；手机 56–60px 只留站名 + 汉堡，副标题隐藏。
- Hero：「AI 额度动态」黑 /「一眼看清」蓝 + 黄色手绘下划线；桌面 56–68px 900；手机 30–38px；吉祥物用独立 PNG，桌面占 28–35% 宽，手机高度 ≤ Hero 55%。

- 标签：重置卡（Codex 浅蓝底蓝字 / Claude 黑底黄字）、全员重置（浅灰）、提额省额（黄）。
- 最近记录：首页 4 条，日期/产品/标签，行高 40–48px，右上「查看全部 →」。
- FAQ：首页 4 条：额度消息来源可靠吗 / 一般多久会再送额度 / 所有人都会收到吗 / 如何查看自己是否有额度。白底细线右侧 >，默认折叠。
- Footer：只留「只收录官方消息 · 不预测下次」，居中 12–14px #727272。
- Tokens：黑 #111111、蓝 #1467F5、蓝深 #0D52D9、黄 #FFEA00、高亮黄 #FFF200、橙红 #FF543D、辅助字 #727272、弱字 #999999、面板 #F7F8FA、边框 #E7E7E7。
- 字体：中文 Noto Sans SC / 思源 / PingFang；英文数字 Inter / Helvetica / Arial；最多两套。
- 圆角：大卡 18–20、小卡 14–16、标签 8–10、按钮 10–12。间距 4/8 网格。阴影最多 0 4px 16px rgba(0,0,0,.05)。
