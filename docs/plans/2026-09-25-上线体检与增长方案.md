## 二、产品还没完善的地方（按对外宣发的优先级）
### 必须做完才宣发
1. **关于页 + 联系方式**：现在没有「谁做的、为什么做、怎么联系」。陌生人判断可信度第一眼看这个。一页即可：作者一句话、数据规则三句、邮箱/公众号。
2. **「数据更新于」回到页脚**：规范把它删了，但它是可信度核心。我定加回，一行小字。
3. **自动收录的模板句清零**：宣发前所有 confidence=auto 的条目补好中文，别让「原文待整理」被截图。
4. **访问统计**：不知道有多少人来、从哪来，等于闭眼开车。Vercel Web Analytics 在项目面板一键开（国内可能被拦），另开百度统计。两个都要你的账号。

### 宣发后一周内
5. **单条事件页 /e/<id>**：每次送额度一个页面，标题「9月23日 Codex 发放重置卡（Plus/Pro/Business）」。这是长尾搜索和转发的落点，首页拿不到长尾。
6. **邮件订阅**：需要你开一个邮件服务账号。候选 Buttondown（RSS 自动发信）或 Kit，我没实测，开了账号我接。
7. **哨兵上云**：GitHub Actions 定时任务免费（公开仓库不限时长，私有仓库每月 2000 分钟够用），10 分钟一次，24 小时不断，不依赖你的 Mac。密钥放仓库 secrets。
8. **国内镜像**：Vercel 现在能开，但随时可能被拦。你有公司主体，可备案后放腾讯云静态托管做国内镜像，百度也爬得更勤。

### 可以放着
- 登录、付费、微信群推送（第三刀，订阅过 200 再说）。
- 质量评分、概率预测：永远不做。

## 三、怎么被搜到
### 现实
- 中文「codex 什么时候重置」：首页是知乎、CSDN、火山引擎、新浪财经的文章，没有实时站。机会在「实时 + 可核验」，但新域名没有权重，得靠外链和内容页。
- 英文「when does codex reset」：OpenAI 帮助中心 + 两个同类站 + 一批攻略博客占满，短期别投入。
- 技术 SEO 已经满分，接下来全是「内容 + 外链 + 提交」的活。

### 按效果排序
1. **搜索引擎提交（你开账号，我做配置）**
   - Google Search Console：添加资源 airesetclock.com，选 DNS 验证，把 TXT 记录发我，我用 DNSPod 加上；然后提交 sitemap。
   - 百度站长平台：同样 DNS/文件验证，提交 sitemap，开「普通收录」推送接口给我 token，我接进发布脚本。
   - 必应：IndexNow 已通，Bing Webmaster 可用 GSC 一键导入。
2. **在事发现场回复**：Tibo 每条重置帖下几千人问「Plus 有吗」「怎么用」。用英文回复一句「分类整理在这里」附链接，中国用户看到中文站。这是零成本精准流量，每次发卡做一次。
3. **中文社区首发（选下一次官方送额度当天）**：Linux.do、V2EX、即刻、知乎「如何看待 Codex 多次重置使用额度」问题下答题。一次即可，别刷。
4. **内容页做长尾**：单条事件页（上面第 5 条）+ 每次事件自动生成一段公众号/知乎短文，标题就用问句。
5. **外链互换**：给 DidReset / WhenReset 发邮件互链（我们引用了它们的线索）；给写过 Codex 攻略的中文博主发一封。新浪财经在转 Tibo 的推文，说明媒体有需求，可作为供稿对象。
6. **标题改问句式**：首页标题已改为「Codex 什么时候重置？Claude 额度什么时候恢复？」，和用户搜索词一致。这条和 UI 规范第 46 节冲突，我定改。

## 四、你可能还不知道的
- OpenAI 现在**卖**即时重置：Plus/Pro 桌面端用量设置里能买，立刻生效、不能存，之后周重置日按你下一次请求起算 7 天。FAQ 已加。
- 重置卡用掉是 5 小时窗 + 周额度一起刷新，并且改你的周重置日期，客服不补发过期卡。
- Vercel Hobby 套餐条款禁止商业用途。现在纯引流站算灰色，一旦挂公司产品建议升 Pro（$20/月）。
- GitHub Actions 能免费当 24 小时哨兵，不用买服务器。
- IndexNow 是必应/Yandex 的即时收录协议，一个 key 文件加一次 POST，已经接在发布脚本里。
